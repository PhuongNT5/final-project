## Key Insights
1. The suite already exists (`eval_utils/`) and has been used for landed results — this phase wires
   it end-to-end over the final artifacts, it does not rebuild statistics from scratch.
2. **Protocol is a first-class field, not a footnote.** Four coexisting protocols must never blur:
   P-A blind 566/125 (test-touch cost 1), P-B k-fold-691, P-C LCO-691, and the declared
   **panel-disclosed LCO** variant. Every row carries its protocol tag.
3. **Paired data demands paired tests.** Every own-vs-own comparison uses McNemar exact (plus the
   discordance bound); `two_proportion_z` on paired predictions is banned outright. K-fold means use
   the Nadeau-Bengio corrected resampled t-test (cite Nadeau & Bengio, *Machine Learning* 2003 — the
   citation currently in the research report resolves to an unrelated AUC-fairness paper).
4. Per-sub-class and per-fold breakdowns are now headline material, not appendix material, because
   the confounding finding *is* the result. Worst-group recall must appear next to pooled BA.
5. The in-domain-minus-OOD gap (k-fold BA minus LCO BA) is itself a reported quantity: for E3,
   82.5 − 69.6 = 12.9pp. It quantifies exactly how much of in-domain performance is camera-bound.
6. Conformal coverage is **marginal only** in this repo; class-conditional coverage is deliberately
   unimplemented. Say that explicitly rather than letting a reader assume the stronger guarantee.

## Requirements
**Functional** — one command regenerates every table; every headline number carries balanced accuracy,
macro-F1, MCC, Cohen's κ, per-class recall, PR-AUC, ROC-AUC, Brier, ECE, cost@10:1, the 0.95-unsafe-
recall operating point, and a BCa bootstrap CI; every comparison carries an exact paired test.
**Non-functional** — deterministic given fixed seeds; outputs markdown + JSON with a git SHA; a
verification pass re-reads the emitted numbers back from the JSON into the number sheet.

## Implementation Steps
1. **[30 min] Freeze the inputs.** Pin: winning token tag, E3 checkpoint hash, T and τ from phase 05,
   sub-task map from phase 02, dedupe policy `drop_conflict`, seed list. Write them into the JSON
   header. Nothing downstream may change an input without re-running the whole phase.
2. **[M4-CPU, 90 min] Pooled protocol tables** — P-B k-fold-691 and P-C LCO-691 for frozen E3 on the
   winning tag, full frozen metric suite per row, BCa CIs (clip-level resampling, not frame-level).
3. **[M4-CPU, 45 min] Declared variant table** — panel-disclosed LCO, emitted in the *same* table as
   the full number so they cannot be separated downstream; the justification text travels in the JSON.
4. **[M4-CPU, 60 min] Breakdowns** — per-sub-class recall with Wilson CIs, per-fold BA, worst-group
   recall, and the in-domain-minus-OOD gap with a CI.
5. **[M4-CPU, 45 min] Paired tests** — McNemar exact for every own-vs-own comparison (baseline tag vs
   each phase-03 variant, calibrated vs uncalibrated); Nadeau-Bengio for k-fold means; Holm correction
   across the pre-declared family from phase 03. Assert in code that no unpaired test is used on
   paired predictions.
6. **[M4-CPU, 30 min] Calibration + safety block** — Brier, ECE/MCE (15-bin, smoothed), reliability
   data, cost@10:1, the operating point, selective-risk curve, marginal conformal coverage with the
   class-conditional caveat stated in the artifact text.
7. **[30 min] Equal-recipe audit.** Every row must be produced by the same recipe. Four-class numbers
   are **historical context only** and may never appear as a baseline row. Flag any table that mixes
   them and hand the list to Lane D.
8. **[USER GO-AHEAD REQUIRED, 30 min] T1 test touch — only if earned.** Pre-register in
   `reports/test-touch-log.md` first: exact model, tag, threshold, metric list, and the claim it
   supports. Then, once:
   ```bash
   cd /Users/nguyenthiphuong/Learning/Proposal/project/my-project
   .venv/bin/python run_relation_transformer.py --binary --arch E3 --tag <winning_tag> \
     --dedupe drop_conflict --dedupe_task binary --seeds 5 \
     --save_logits sweep_results/relation_tokens/T1_blind_logits.pt
   ```
   > **NOTIFY USER BEFORE RUNNING** — this spends test touch T1 of 2 and is irreversible. Do not run
   > it to "check" anything; run it only to report the pre-registered claim.
9. **[45 min] Freeze + verify.** Stamp the artifact, then run `eval_utils/verify_against_csv.py` (or
   the JSON equivalent) to confirm that every number Lane D has transcribed matches the artifact.
   **After this point: no new experiments.**

### Pre-registered reporting rules
| Rule | Statement |
|---|---|
| Headline | frozen E3, LCO-691 full, at the test-observed prior. Panel-disclosed reported beside it. |
| Test touches | P-C/P-B = 0 touches. T1 = 1 touch, pre-registered, user-approved. T2 reserved for a post-freeze defect only. |
| Paired comparisons | McNemar exact + discordance bound. Unpaired z-tests on paired data are a defect, not a style choice. |
| Negative results | any lever that failed its phase-03/04/05 rule appears in the tables with its failure, not omitted. |
| Four-class numbers | historical context only; never a baseline row (equal-recipe rule). |

## Risk Assessment
| Risk | L | Impact | Mitigation |
|---|---|---|---|
| A late defect after the freeze | Med | Re-run pressure | T2 exists exactly for this; any re-run re-stamps the whole artifact, never a single row |
| Unpaired test slips into a comparison | Med | **Defence-fatal** | Code assertion + phase-10 defect hunt |
| Panel-disclosed number quoted alone downstream | **High** | Credibility | Emitted only as a paired column; number sheet stores protocol as a required field |
| CIs so wide the headline is not significant | **High** | Narrative | Expected at n=691 with 8 folds; the contribution is the mechanism, not the point estimate — phase 11 wording covers it |
| Seed variance mistaken for a real delta | Med | Med | Seed-averaged, and seed spread reported alongside |
| Conformal coverage over-claimed | Med | Med | Marginal-only caveat is part of the emitted artifact text |
